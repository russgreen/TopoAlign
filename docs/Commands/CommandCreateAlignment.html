Create Alignment

Creates a Revit native alignment from model/detail lines and arcs, from points picked in plan, or from curves on a CAD drawing. The command validates curve continuity, lets you control start station and direction, can optionally drape the profile on a toposolid, and can delete the source lines after creation.

Usage / Steps

  1. Launch Create Alignment from the Topo Align ribbon panel.
  2. Set alignment name, start station, and units.
  3. Choose where the geometry comes from under Geometry from: lines/arcs, points or CAD.
  4. Pick the geometry (see below), then optionally add transition spirals.
  5. Optionally reverse direction and/or delete source lines.
  6. Optionally tick Drape profile on toposolid, click Pick toposolid, set the sampling options and click Preview profile to check the result.
  7. Click Create Alignment.

Options / Parameters

  • Alignment name — Name for the new alignment element.
  • Start station — Displayed start station value (converted using selected units).
  • Lines/arcs — Accepts model and detail curves (line/arc only), chained into one continuous run.
  • Points — Pick the points of intersection (PIs) of the alignment in plan; press Esc when finished. The grid lists each point with a Radius and a Spiral length you can edit. A radius of 0 leaves a sharp corner, and the first and last points are the ends. Default radius is used for newly picked points.
  • CAD — Pick lines, arcs or polylines on an imported or linked DWG/DXF. Splines and ellipses are not supported.
  • Add transition spirals — Puts a clothoid spiral of the given length either side of every curve. The PIs and radii stay where they are, so the curve moves slightly inside the original lines. For picked lines/arcs, spirals are added to every arc that sits between two straights and is tangent to them. Any other arc (at the start or end of the chain, next to another arc, or too tight for the spiral length) is kept as drawn, and the summary after creating lists which ones were skipped.
  • Reverse direction — Reverses stationing direction before creation.
  • Delete source lines — Removes selected source curve elements after successful creation.
  • Drape profile on toposolid — Builds the vertical profile from the ground instead of a flat profile. Works with a Toposolid (Revit 2024+) or a topography surface.
  • Pick toposolid — Selects the ground to drape on. A toposolid you have already selected is used without asking.
  • Sample interval — Distance between ground elevation samples along the alignment. The end of every line and arc is always sampled.
  • Vertical tolerance — How far the profile may stray from the sampled ground. Larger values give fewer, simpler PVIs; smaller values follow the ground more closely.
  • Elevation offset — Added to the ground elevation. Positive values lift the profile above the ground, negative values lower it.
  • Min vertical curve length — Rounds each change of grade with a parabolic vertical curve at least this long (shortened where PVIs are close together). Leave at 0 for straight grades between PVIs.
  • Preview profile — Reports the number of PVIs, the elevation range and the steepest grade before anything is created.

Notes

  • Revit stores spirals as a series of very short straights (within about 1.5 mm of the true curve); the alignment length is the length of those straights.
  • The alignment is generated directly from the picked lines and arcs; no existing alignment is needed. Without draping, the profile is flat at the elevation of the first curve.
  • The start and end of the alignment must be over the toposolid. If other stations fall off it, the profile is bridged across the gap and the preview says how many were affected.
  • Stations are measured along the plan length of the lines and arcs, so a sloping line is measured by its horizontal length.
