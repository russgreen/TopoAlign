Create Alignment

Creates a Revit native alignment from selected model/detail lines and arcs. The command validates curve continuity, lets you control start station and direction, and can optionally delete source lines after creation.

Usage / Steps

  1. Launch Create Alignment from the Topo Align ribbon panel.
  2. Set alignment name, start station, and units.
  3. Click Pick lines/arcs and select a continuous chain of model/detail curves.
  4. Optionally reverse direction and/or delete source lines.
  5. Click Create Alignment.

Options / Parameters

  • Alignment name — Name for the new alignment element.
  • Start station — Displayed start station value (converted using selected units).
  • Pick lines/arcs — Accepts model and detail curves (line/arc only).
  • Reverse direction — Reverses stationing direction before creation.
  • Delete source lines — Removes selected source curve elements after successful creation.

Notes

  • Requires Autodesk Civil Alignments support in the installed Revit version.
  • The alignment is generated directly from the picked lines and arcs; no existing alignment is needed. The profile is flat at the elevation of the first curve.
