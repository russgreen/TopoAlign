Edit Alignment

Changes an existing native Revit alignment: rename it, move its start station, reverse its direction, move its points, or change the radius and spiral length of its curves. It works on any alignment in the model, including ones made by other tools.

Usage / Steps

  1. Select an alignment in the model first, or launch Edit Alignment and click Pick alignment.
  2. Change the name, the start station, or tick Reverse direction.
  3. To change the shape, work in a plan view. Select a point in the list and click Move point to pick its new position, or type new X and Y values. Edit the Radius and Spiral of any curve in the list, or use Add point and Remove point.
  4. Click Apply.

Demo Video

Options / Parameters

  • Alignment name — The new name. The alignment type in the browser is renamed to match.
  • Units — The units used to show and enter the start station.
  • Start station — The station at the start of the alignment. Changing it shifts every station along the alignment; the geometry does not move.
  • Points — The points of intersection of the alignment, with the radius of the curve at each and the length of its transition spirals (each end of the alignment is a point with no curve). A radius of 0 leaves a sharp corner. The blue line in the plan view shows the result while you pick a position.
  • Move point / Add point / Remove point / Reset — Move the selected point to a position picked in the view, add a point where you click (on the nearest straight, or beyond either end), remove the selected point, or go back to the alignment as it was opened.
  • Reverse direction — Runs the alignment the other way. The vertical profile is mirrored with it, so every point on the ground keeps its elevation. Available for alignments made of straights, arcs and parabolic vertical curves.

Notes

  • Apply is only available once something has changed.
  • If an alignment contains a kind of curve that can't be mirrored, the dialog says so and leaves reverse unavailable; renaming and moving the start station still work.
  • Points can only be edited on alignments made of straights joined by sharp corners or by arcs, with or without equal entry and exit spirals (such as those made by Create Alignment). Spirals are stored as short straights and are recognised from their shape; for any other alignment the dialog says why the points can't be edited.
  • When the edit changes the length of the alignment, the vertical profile keeps its stations and its last grade is extended or trimmed. An edit that would end the alignment before the last profile station is refused; use Edit Profile first.
  • Station labels already placed on the alignment are not moved by this command; place them again after reversing.
  • To add stations to the vertical profile or change their elevations, use Edit Profile.
