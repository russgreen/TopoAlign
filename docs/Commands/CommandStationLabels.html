Station Labels

Places a set of station labels along a native Revit alignment in the active view, using Autodesk's own station label type.

Usage / Steps

  1. Open the plan, section or elevation view that should show the labels.
  2. Select an alignment first, or launch Station Labels and click Pick alignment.
  3. Choose a label type, the interval and the range, then click Create Labels.

Options / Parameters

  • Label type — The spot dimension types that Autodesk accepts for alignment station labels. If the model has none suited to label sets, New recommended type creates one (labels that rotate with the alignment, vertical text, station value, heavy tick leader).
  • Units — The units used for the interval, offset and stations below.
  • Interval — The distance between labels. Leave blank for the default (100 ft in imperial projects, 1000 m in metric).
  • Offset (paper) — The distance from the alignment on the printed sheet. Positive is to the right of the alignment, negative to the left. Leave blank for the default (1/8 inch or 5 mm).
  • From station / To station — Limits the labels to part of the alignment. Leave blank to use its full range.
  • Leader line — Draws a leader from each label to the alignment.

Notes

  • Labels can only be placed in plan, section and elevation views; 3D views, schedules and sheets are not supported.
  • Requires Autodesk Civil Alignments support in the installed Revit version.
  • Each label is a normal Revit element and can be moved, edited or deleted afterwards.
