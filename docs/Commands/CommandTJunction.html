T-Junction

Joins a side road alignment to a main road alignment. The side road is trimmed (or extended) to the centreline of the main road, and two new alignments are created for the kerb returns, one on each side of the side road.

Usage / Steps

  1. Select the main road alignment and then the side road alignment in the model first, or launch T-Junction and use Pick main road alignment and Pick side road alignment.
  2. Enter the Kerb radius and the half-width of each road (the distance from its centreline to its kerb).
  3. A preview of the trimmed side road and the kerb returns is drawn in the active plan view. Click Create T-Junction.

Options / Parameters

  • Units — The units used to enter lengths.
  • Kerb radius — The radius of the kerb returns.
  • Side road half-width — Distance from the side road centreline to its kerb. Use 0 to fillet between the centrelines.
  • Main road half-width — Distance from the main road centreline to its kerb. Use 0 to fillet between the centrelines.
  • Pick main road element (optional) — Available once the main alignment is chosen. Pick the element that models the main road surface (a road, floor, toposolid and so on). The kerb levels at the main road are then read from its top surface at each kerb return end, so crossfall or camber is picked up instead of the alignment profile level. Where the check misses the element the alignment level is used. Clear removes the element.
  • Main kerb level offset — A fixed amount added to the main road level at the kerb returns, after any picked element. Negative values lower the kerbs. The dialog shows the resulting left and right kerb levels relative to the main alignment profile.
  • Create road surface at the junction — Also makes the road surface where the roads meet as a separate piece of geometry (a thin solid in Roads, Hardscape or Generic Models). Its top follows the side road's elevation at the side road end, the main road's elevation along the main road kerb, and changes evenly round the kerb returns. Surface thickness is measured down from the top.
  • Use the other end of the side road — When both ends of the side road reach the main road, the nearer end is used. Tick this to use the other.

Notes

  • The main road is not changed.
  • The side road must end in a straight where it meets a straight of the main road. Its profile is kept, with the last grade extended or trimmed to the new length.
  • The kerb returns are new alignments named after the side road, for example "Side kerb L" and "Side kerb R" (left and right when travelling towards the main road). Each runs from the side road kerb to the main road kerb. Its profile runs from the side road's elevation at its start to the main road's elevation at its end, so the kerb returns line up vertically with the roads.
  • The command refuses when the kerb return would be longer than the side road or run off the end of the main road straight; use a smaller radius.
