Edit Profile

Adds stations to the vertical profile of an existing alignment and sets the elevation of each one. Use it to refine a profile after it has been created: pull a crest up, lower a sag, or pin the road to a level at a particular station.

Usage / Steps

  1. Select an alignment in the model first, or launch Edit Profile and click Pick alignment. The grid lists the stations of its profile.
  2. To add a station, enter its station in New station (and a Curve length if you want it rounded) and click Add station. Its elevation starts on the existing profile, so adding it changes nothing until you edit the elevation.
  3. Type new values in the Elevation, Station or Curve length cells. Select a station and click Remove station to delete it, or Reset to go back to the profile you started with.
  4. Click Apply.

Options / Parameters

  • Units — The units used to show and enter stations, elevations and curve lengths.
  • Station — The station of the point of vertical intersection (PVI), including the alignment's start station. The first and last stations stay at the ends of the alignment.
  • Elevation — The project elevation of the PVI. The first and last elevations can be changed too.
  • Curve length — The length of the parabolic vertical curve rounding the PVI. 0 leaves a sharp change of grade.
  • Curve used — The curve length that is actually written. A curve may use at most half of the straight on each side of it, so it is cut back when stations are close together, and it is blank where the grade does not change.
  • Grade to next — The grade of the straight between this station and the next.

Notes

  • Requires Autodesk Civil Alignments support in the installed Revit version.
  • Apply is only available once something has changed and the stations are valid: in order, at least two, and no negative curve lengths. The status line says what to fix.
  • Only the profile changes. The plan geometry, length, name and start station stay as they were, and so do station labels.
  • Existing vertical curves keep their length. If a curve is not symmetrical about its PVI it is rebuilt symmetrical.
  • Profiles that contain a kind of curve other than straights and parabolic vertical curves can't be edited here; the dialog says so.
  • A road made earlier with Sweep Along Alignment is not updated; run that command again to follow the new profile.
