Align Topo Edges

Adds points to two topos that share an edge so that the edges line up. Where the outline of one topo has a point along the edge of the other, a matching point is added to the other, at the same height.

Usage / Steps

  1. Launch the command.
  2. Select the topo to add points to.
  3. Select the neighbouring topo that shares an edge with it.
  4. Choose whether both topos get points, or only the first.
  5. The points are added and a summary is shown.

Demo Video

Options / Parameters

  • Both topos — each topo gets the other's edge points, so the shared edge has identical points on both sides.
  • First topo only — the second topo is left alone and the first gets its edge points and has its matching points moved.

Output / Results

  • Points are added on the outline of the topo, at the plan position and height of the neighbour's edge point.
  • Points that already exist on both topos at the same height are left alone.
  • Every existing point on the first topo's shared edge is aligned to the second topo's edge height. Points between the second topo's vertices use the height interpolated along that edge.
  • The second topo's existing points are never moved. Pick the topo whose heights you want to keep second.

Tips & Pitfalls

  • The outlines must meet to within about 3 mm (0.01 ft) in plan to count as a shared edge.
  • Holes in a topo are treated as edges too, so topos that meet at an inner boundary also work.

Troubleshooting

  • The two topos do not appear to share an edge → Check that the topos touch, and that their boundaries line up in plan.
  • Revit would not accept the new points → Check the topo is not in a state that stops points being edited, then try again.
